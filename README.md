# Kenyatta National Hospital Management System

## Project Overview

This project is a hospital data management and monitoring system developed for Kenyatta National Hospital (KNH).

The system manages data generated by 12 critical sensors:
- 5 Heart Rate Monitors
- 5 Temperature Sensors
- 2 Water Usage Meters

The project uses Python and Bash scripts to generate, manage, secure, analyze, and archive hospital sensor data.

## Project Files

### hospital_system.py
Generates simulated sensor data for heart rate, temperature, and water usage.

To start the system:

./hospital_system.py start

To stop the system:

./hospital_system.py stop

### hospital_admin.sh
Initializes the hospital directories and secures the active logs directory.

Run:

./hospital_admin.sh

### hospital_analysis.sh
Analyzes hospital sensor data and produces reports.

Run:

./hospital_analysis.sh

### hospital_archive.sh
Archives hospital sensor logs.

Run:

./hospital_archive.sh

## Data Directories

- active_logs/ - stores current sensor data
- archived_logs/ - stores archived sensor data
- reports/ - stores generated analysis reports

These directories are excluded from Git using .gitignore because they contain generated data.

## How to Run the Project

Make the scripts executable:

chmod +x hospital_admin.sh
chmod +x hospital_archive.sh
chmod +x hospital_analysis.sh
chmod +x hospital_system.py

Initialize the hospital environment:

./hospital_admin.sh

Start the hospital data system:

./hospital_system.py start

Run the analysis:

./hospital_analysis.sh

Archive the logs:

./hospital_archive.sh

Stop the hospital data system:

./hospital_system.py stop
