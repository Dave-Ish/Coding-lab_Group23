# KNH Digital Infrastructure Project

## Project Overview

This project was developed for Kenyatta National Hospital (KNH) to help secure and manage data generated by critical hospital sensors.

The system works with sensor data including:
- Heart Rate
- Temperature
- Water Usage

## Project Objectives

- Secure hospital data and files
- Manage file permissions
- Detect emergency conditions
- Calculate facility averages
- Automate system administration tasks
- Use Git and GitHub for team collaboration

## How to Run

First, make the administration script executable:

chmod +x hospital_admin.sh

Then run:

./hospital_admin.sh

## Project Structure

- active_logs/ - stores active sensor logs
- archived_logs/ - stores archived logs
- basics/ - contains basic project scripts
- reports/ - contains generated reports

## Team Roles

Each team member contributes to different parts of the project, including:
- Execution logic
- Security and permissions
- Documentation
- Data analysis
- Repository management
